# Inference-engine patch waiver — PR #4047

The GB300 Kimi-K3 AgentX recipes in this PR apply the following Python-source
patches to `vllm/vllm-openai:nightly-77154ca6116ae34cbfe314beef1016bde9b63989`.
They also install the official `tokenspeed-mla==2.0.3` and FlashInfer 0.7.1
Python, cubin and CUDA 13.0 JIT-cache packages, including their matching
architecture-specific cache providers, without changing unrelated dependencies.
The setup script checks each patch before applying it and
accepts an already-applied patch on repeated startup.

| Commit | Change |
|---|---|
| [fc200bec9e](https://github.com/wzhao18/vllm/commit/fc200bec9e37d076719fc74b8ff9600476468544) | Add independent CuTe prefill selectors and align metadata without GPU copies. Only context attention is enabled. |
| [2454c49e76](https://github.com/wzhao18/vllm/commit/2454c49e76b9418f7b5c99c3fcdc492d1a5b28e4) | Route quantized Kimi output projections through their linear method instead of BF16 `addmm_`. |
| [92a227beef](https://github.com/wzhao18/vllm/commit/92a227beeff06f0dca827a4051f35b8ed6a5e9e1) | Pass the expected activation dtype to online-quantized MLA KV projections. |
| [a4489428a6](https://github.com/wzhao18/vllm/commit/a4489428a6c5215f929466289731e625ac9b2e83) | Upgrade the official TokenSpeed MLA dependency to 2.0.3; implemented through package installation. |
| [vLLM #60948](https://github.com/vllm-project/vllm/pull/60948) | Upgrade the official FlashInfer Python, cubin and JIT-cache packages to 0.7.1. |

The source patches are rebased onto the pinned image revision. Only `vllm/`
files are applied inside the serving image; tests are retained in the patch
files for provenance. No CUDA extension rebuild is required.

The unmodified image lacks the CuTe selection flags. Its online-FP8 Kimi path
fails first at the routed projection's raw BF16 `addmm_`, and then at the MLA KV
projection when an FP8 input is passed to a method expecting BF16 activations.
The two fixes allow the requested decode-only target-linear quantization to run.

DSpark constructs its own draft quantization configuration and does not inherit
the target's `quantization-config`. Draft weights, activations and KV precision
retain the pinned upstream handling of the shipped checkpoint. Embeddings, LM
head and checkpoint MXFP4 routed experts are unaffected by online linear FP8.

Remove the patches and setup script after pinning an official nightly that
contains these changes, TokenSpeed MLA 2.0.3 or newer, and FlashInfer 0.7.1 or newer. Keep the configuration
flags only where that image supports them. This document records the requested
exception; it does not claim maintainer approval or an optimized-combination
evaluation result.
